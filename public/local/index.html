EVE Online Local chat for your Twitch stream.

What it is

A free OBS browser source that makes your Twitch chat look like EVE Online's Local chat. No accounts, registration or login required.

Avatars are fetched from IVR (api.ivr.fi). We record which channels load the overlay (channel name only) to measure usage and tell streamers about updates. No viewer data is collected.

Add it to OBS

  1. In OBS: Sources → + → Browser
  2. Paste your URL into the URL field
  3. Set width and height to the OBS Browser Source size shown under Customise
